Aseprite - Criar/editar Spritesheet e salvar como Bitmap.

Tiled - Usa os sprites criados no Aseprite para criar Tile Map por camadas e salva as coordenadas como JSON 
(sempre usar a opção de incorporar conjunto de tiles para não ser necessário buscar informações externas nos arquivos tsx).

DotTiled - Dependência instalada via NuGet no Visual Studio, este lê o JSON criado no Tiled para renderizar o mapa no MonoGame.
